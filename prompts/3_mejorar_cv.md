# Prompt 3 — Mejorar mi CV (buenas prácticas)

Claude ya lo aplica solo en el Paso 3. Si quieres mejorar un CV aparte (en Claude Code o en claude.ai), adjunta tu CV y pega esto:

```
Mejora mi CV con estas reglas:

1. NO inventes nada: ni experiencia, ni años, ni herramientas, ni cifras, ni títulos. Si algo no está claro, pregúntame antes de escribirlo.
2. Una sola página. Orden: datos de contacto, titular, perfil (2-3 líneas), competencias, experiencia, proyectos, formación, idiomas.
3. Cada experiencia: 2-3 puntos que empiecen con un verbo concreto ("Atendí", "Armé", "Vendí", "Organicé") y digan qué hice y, si existe, el resultado con números.
4. Que suene a una persona real: frases cortas y concretas. Prohibido: "me apasiona", "proactivo y orientado a resultados", "altamente motivado", "aportar valor", "sinergia", "en el dinámico mundo de", listas de tres adjetivos y guiones largos.
5. Compatible con sistemas de selección (ATS): texto simple, sin tablas complejas, sin íconos ni barras de "nivel de habilidad", títulos de sección estándar, palabras clave del área que busco.
6. Nada de datos innecesarios: DNI, estado civil, dirección completa o fecha de nacimiento no hacen falta.
7. Correo profesional (nombre.apellido@...) y un teléfono con código de país.

Las áreas a las que me postulo son: [completa].

Primero dime en una lista corta qué cambiarías y por qué. Después dame el CV completo mejorado.
```
